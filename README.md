# Advanced Book Data Web Scraping & Analysis

## Objective
Developed a Python-based web scraper to collect and analyze book data from a multi-page website.

## Features
- Scraped 1000+ books
- Search books by name
- Export to CSV and Excel
- Top 10 expensive books
- Top 10 cheapest books
- Rating analysis
- Data visualization

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Excel
