# 📚 Book-Data-Analytics-System


## 📌 Project Overview
This project is a Python-based web scraping and data analysis application developed to automate the extraction of book information from a multi-page online book catalog. The scraped data is cleaned, analyzed, and exported into CSV and Excel formats to generate meaningful insights.

---

## 🎯 Objective
- Automate data collection from a website.
- Clean and organize scraped data.
- Perform exploratory data analysis.
- Generate reports for business insights.
- Provide a simple search feature for quick data retrieval.

---

## ✨ Features
- ✅ Multi-page web scraping (1000+ book records)
- ✅ Extracts Book Name, Price, Rating, and Availability
- ✅ Stores data in CSV format
- ✅ Exports analysis to Excel
- ✅ Calculates:
  - Average Price
  - Highest & Lowest Price
  - Top 10 Most Expensive Books
  - Top 10 Cheapest Books
  - Rating Distribution
- ✅ Search books by name
- ✅ Data visualization using Matplotlib

## 🚀 How to Run

### Clone the repository

```bash
git clone <repository-link>
```

### Install dependencies

```bash

```

### Run the scraper

```bash
python scraper.py
```

### Analyze the data

```bash
python analysis.py
```

### Search a book

```bash
python search.py
```

### Generate graph

```bash
python graph.py
```
